## D-HA1: literal codecs at the existing broker dispatcher

The existing `server::call` already routes peer send/answer/hand from ordinary MCP
and code mode to `broker::Request`. The native adapters borrow validated packets,
return fixed canonical tool identities/arguments, and stream native result
envelopes. They neither choose a principal nor open files, processes, credentials,
stdin or network connections. Reported thread/turn/call labels remain
adapter-reported correlations. Only the private instance's authenticated caller
and checked grants may authorize the canonical operation.

The fixed supported tool mapping in this checkpoint is `send`, `answer`, `hand`.
Queue-consuming `receive` requires a separate pre-consumption result reservation
contract and is not silently included. This is not the entire Codex/Claude builtin contract.
Unimplemented native effects, external tools, hooks and approval requests return
typed unsupported outcomes. A decoded request is not authorization or evidence
that a hostile harness used that protocol for any other effect.

State transitions for the codec are `received -> rejected(typed cause)` or
`received -> validated borrowed request -> canonical broker -> typed completion
-> native response`. The canonical broker retains authorization/reservation and
actual effect state. A response write error returns its IO error and cannot
change the actual effect to not-started. `Request::reserve_reply` counts the exact
empty native envelope, adds at most six escaped bytes per broker result byte,
and reserves fallibly. The slot borrows the request which prepared it, so filling
cannot substitute another packet's correlation IDs. `ReplySlot::finish` checks the broker result bound and
uses a fixed writer that cannot grow the buffer. The canonical broker must supply
its actual reserved result bound before execution; that getter/caller span is
pending ROOT/audit-owner coordination. No infallible post-effect wrapper allocation.

No handshake/process ledger, timer, queue, cache, periodic probe or alternate
state owner is introduced. There is no transparent retry or replay on transport
failure. Native output channels remain exact separately captured bytes; codecs
accept explicit control packets, never sniff stdout/stderr for control.

Production literals: exact version strings, native field/method/tool names and
JSON success/error forms come from the pinned sources above. Namespace/server
`shards` selects this deliberately registered tool family and cannot select
authority. JSON string escapes, control range0x00–0x1f, hex digits, shift4 and
mask0xf implement RFC8259§7; signed64-bit native request IDs follow pinned Codex
rpc.rs. No upstream default, timeout, buffer size or measured number is adopted
as runtime policy. The local probes'30/45-second deadlines are explicit finite
fixture inputs, not production constants.

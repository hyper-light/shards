# D229 event observation literals and boundaries

This extends the existing on-demand metrics seam under ROOT's explicit GO. The
[contract and pinned primary sources](PROPOSAL.md) define the selected behavior.
It neither issues rights nor changes the existing local limit contract.

| Added literal/representation | Source or derivation; failure/cold-start behavior |
| --- | --- |
| memory.events; pids.events | Fixed kernel cftype names in Linux6.18.48 renderers. Existing held-directory openat/O_NOFOLLOW/CLOEXEC and reused page apply. No fallback, creation, writes or ancestor lookup; open/read errno is retained. |
| low/high/max/oom/oom_kill/oom_group_kill; task max | Six keys from `__memory_events_show`, one from `__pids_events_show`. Seven enum slots are exactly this union with distinct memory/task max variants. Unknown kernel keys are skipped through their line and never become labels. Missing selected key is Missing; duplicate/malformed/missing value is Invalid; token/numeric overflow is Overflow. |
| ALL array width7 | Six memory streams plus one task stream, not a budget or learned threshold. Snapshot, parser storage and event iteration derive their bounds from this array. Values are independent cumulative streams, not a unique-incident total. |
| shards.cgroup.memory.events; shards.cgroup.task.events | ROOT-approved custom instruments because pinned semconv lacks this exact cgroup-source family. They retain configured base-file aggregation, not unconditional local or subtree semantics. No observed mode, process or admission claim is invented. |
| {event}; cumulative2; isMonotonic=true | Count annotation and existing OTLP Cumulative enum2; raw kernel counters. Genuine observed0 is emitted. Unknown birth time remains omitted/default0, and continuity across recreation/restore/wrap/mount-mode changes is unproved. No rates, deltas, resets or start timestamps are synthesized. |
| shards.cgroup.event and its fixed values | Enum-derived point attribute, including diagnostics. It distinguishes memory/task event series and each same-cause memory error; untrusted text cannot enlarge cardinality. No Resource attribute changes. |
| u64 parser / exact nonnegative int64 wire | Kernel memory unsigned-long/pids signed64 rendering, existing checked decimal grammar and OTLP sfixed64 `as_int`. Above-i64 finite counts are omitted with Overflow; no float conversion, clamp, wrap or synthetic0. Negative text is invalid. Long value tokens exceed the retained numeric grammar and are Overflow. |
| Parser Key/Value/End/Other states | The fixed line grammar: a known key needs exactly one value; extra tokens invalidate only that selected line. A duplicate keeps that slot Invalid. An unknown line, including very long words, is skipped until Line. File-level I/O failure invalidates all selected observations from that incomplete file. |
| One reused page / existing TOKEN_BYTES | No new buffer bound. The longest selected event key is14 bytes, below the existing `wbytes=` plus20-decimal-digit u64 bound27. Reader's actual fallible sysconf page is reused over all files/scopes. This source observation is not a measured allocation claim. |
| 7 numeric +0–7 error-detail points / attempted scope | At most one numeric point or one error per selected stream. Two added numeric descriptors. Existing error-count semantics count failed observations, not I/O syscalls; six limit-state indicators and canonical run/VM/member lineage remain unchanged. Whole-request size and collection/encoding/parent/kernel costs remain ROOT measurements. |
| Private test pins/envelope | Product Cargo.lock libc0.2.189; official generated-proto0.33.1 with existing feature pins and serde1.0.151. Linux2CPU/2GiB/4GiB,600s/j2 is the owner's admitted light scope, not production policy or measured physical peak. Existing installed1.98.1 is selected explicitly; repository rust-version is MSRV, not a toolchain pin. |

The native codec streams an iterator over the existing observations and these
seven slots. The official reference constructs allocated generated request objects
and now also constructs an observation Vec; that adapter construction is part of
the encoding baseline. No equality postprocessing, SDK-pipeline claim, syscall
inference or overhead allowance is introduced. Profile source changes are input
fields only, and its two feature configurations are compile checks only.

The collection is non-atomic: different file reads, values and scopes can observe
different instants; the timestamp does not prove an atomic cut or causal writer.
Neither configured ceilings nor these cumulative event observations establish
effective ancestor capacity, protected entitlement, owner policy or admission.
